# Установка и загрузка модулей RestoApp

Для загрузки дополнительных модулей используйте официальный CLI:

1. Установите webresto CLI глобально:

```bash
npm i -g @webresto/cli
```

2. Перейдите в папку, где находится папка `modules` вашего проекта.

3. Выполните команду для установки нужного модуля:

```bash
webresto install %name-module%
```

Если модуль бесплатный, он будет скачан и установлен автоматически.
