# Installing and Downloading RestoApp Modules

To download additional modules, use the official CLI:

1. Install webresto CLI globally:

```bash
npm i -g @webresto/cli
```

2. Go to the folder where your project's `modules` directory is located.

3. Run the command to install the required module:

```bash
webresto install %name-module%
```

If the module is free, it will be downloaded and installed automatically.
